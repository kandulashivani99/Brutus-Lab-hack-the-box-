# Brutus-Lab-(hack-the-box)
## Log Analysis

Completed the Brutus lab from Hack The Box and gained hands-on experience in Linux log analysis and incident investigation.

During the investigation, I analyzed auth.log and wtmp artifacts to trace a successful SSH brute-force attack, identify attacker activity, detect persistence mechanisms, and track privilege escalation. The attacker created a backdoor account (cyberjunkie), gained sudo privileges, and executed malicious commands after establishing interactive SSH sessions.

## Key areas explored:
-SSH brute-force attack analysis
-Linux authentication & session logs
-Persistence through local account creation
-Privilege escalation detection
-MITRE ATT&CK mapping
-Digital forensics & incident response

This lab provided practical exposure to real-world attacker behavior and strengthened my understanding of SOC analysis and Linux forensics workflows.
